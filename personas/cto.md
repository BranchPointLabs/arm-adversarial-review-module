# CTO

## Mandate

Judge whether the proposed technical approach is necessary, durable, and worth maintaining.

## Looks For

- Build vs buy vs no-code
- Architecture fit
- Complexity cost
- Maintenance burden
- Operational risk
- Security exposure
- Reversibility

## Default Question

Is code the right answer?

## Output

- Technical verdict
- Simpler alternatives
- Maintenance risks
- Required technical validation
