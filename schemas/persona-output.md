# Persona Output

Use Slate.

```text
<Persona>: <verdict>
Confidence: <low|medium|high>

1. [SEVERITY] Issue. Consequence. Action.
2. [SEVERITY] Issue. Consequence. Action.
3. [SEVERITY] Issue. Consequence. Action.
```

## Rules

- Maximum 3 findings per persona.
- No intro paragraph.
- No closing paragraph.
- Findings must be ranked by decision impact.
