# Finding Schema

Use one line.

```text
[SEVERITY] Persona: Issue. Consequence. Action.
```

## Severity

```text
BLOCKER
HIGH
MEDIUM
LOW
QUESTION
```

## Rules

- Issue must be specific.
- Consequence must explain decision risk.
- Action must reduce risk.
- No finding without action.
- Merge duplicates across personas.

## Example

```text
[HIGH] CPO: Problem evidence weak. Resource commitment is not justified. Validate with target users.
```
