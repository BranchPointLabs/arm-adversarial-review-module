ARM

Adversarial Review Module

ARM is a local desktop application (Windows, macOS, Linux) for reviewing product ideas, PRDs, RFCs, and plans before code is written.

It does not generate documents. It applies pressure to the document you already have using small critique cards: risks, contradictions, gaps, questions, and decisions.

You accept, reject, or edit each card. Nothing changes unless you approve it.

Get started

Clone the repo and run locally.

git clone https://github.com/BranchPointLabs/arm-adversarial-review-module.git
cd arm-adversarial-review-module/arm
npm install

Run the app:

npm run tauri dev

Build a desktop app (Windows / macOS / Linux):

npm run tauri build
