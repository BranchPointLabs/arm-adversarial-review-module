Workflow

From artifact to sharper decision.

01

Load the artifact

Pass in an idea, PRD, RFC, executive memo, or pasted stdin. ARM preserves the artifact context and applies the right command contract.

02

Apply review lenses

Critic, product, technical, quality, security, and user lenses look for contradictory assumptions, missing evidence, and execution risk.

03

Emit Slate output

Reviews are compact by design: numbered findings, severity, owner lens, and a direct next step. No sprawling memo archaeology.

Review Lenses

Designed to create useful friction.

ARM is not trying to be agreeable. It assembles multiple perspectives and collapses duplicates into a single review that helps teams decide what to fix, prove, or abandon.

CLI

Run it locally with plain Node.

node ./bin/arm.js status
node ./bin/arm.js validate
node ./bin/arm.js review idea examples/idea.md
node ./bin/arm.js review roast examples/idea.md --no-write
node ./bin/arm.js decide examples/idea.md
