ARM

Product documents do not need more text. They need more pressure.

BMAD optimizes for fast document generation. ARM optimizes for control, correctness, and defensible decisions.

Ask targeted questions. Get structured critique. Accept only what survives review.

Direct contrast

ARM exists because generating the document is the easy part.

BMAD

  • Generates large documents quickly.
  • Requires the documentation to be comprehensive.
  • May miss key flows inside oversized artifacts.
  • Creates output that is slow to read and evaluate.
  • Can introduce new requirements across generations.
  • Leaves accuracy checking to the user.

ARM

  • Reviews the document you already have.
  • Uses targeted questions instead of blanket generation.
  • Returns small review cards, not sprawling prose.
  • Lets the user accept, reject, or edit every change.
  • Captures decisions, notes, risks, and open questions.
  • Keeps the document auditable as it evolves.

BMAD optimizes for output. ARM optimizes for direction.

The problem

Document generation is fast. Document evaluation is slow.

Large generated documents create a hidden maintenance burden. A small wording change can alter meaning. A later generation can add requirements. A missed flow can disappear inside pages of plausible text.

The user still has to meticulously inspect the output for inaccuracies, contradictions, scope creep, and implied commitments. As the document grows, the cost of verifying it grows with it.

That is the failure ARM is designed around: high maintenance, low auditability, and too much trust placed in generated prose.

How it works

Ask. Review. Decide. Maintain.

  1. Ask Ask a specific question about a PRD, idea, RFC, or plan.
  2. Review ARM returns focused critique cards: risks, contradictions, questions, actions, and decision candidates.
  3. Decide Accept, reject, or edit each card before it affects the document.
  4. Maintain Log decisions, add notes, track open questions, and evolve the document without losing control.

Principles

Control and correctness over speed.

  • Evaluation over generation.
  • Direction over output.
  • Auditability over volume.
  • Accepted decisions over generated prose.

BMAD helps produce documents. ARM helps keep product decisions correct, controlled, and reviewable.
